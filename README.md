## 1. ภาพรวมโครงการ

Book Tracking Web Application เป็นเว็บแอปพลิเคชันสำหรับจัดการคลังหนังสือส่วนตัวและติดตามพฤติกรรมการอ่านของผู้ใช้งาน ผู้ใช้สามารถบันทึกข้อมูลหนังสือ จัดหมวดหมู่ ติดตามความคืบหน้าการอ่าน ตั้งเป้าหมายการอ่าน บันทึกความคิดเห็น และดูสถิติการอ่านของตนเองได้

ระบบมีวัตถุประสงค์เพื่อช่วยให้ผู้ใช้จัดการหนังสือได้อย่างเป็นระบบ สามารถติดตามหนังสือที่อ่านแล้ว กำลังอ่าน และต้องการอ่านในอนาคต รวมถึงส่งเสริมให้ผู้ใช้อ่านหนังสืออย่างสม่ำเสมอ

## 2. วัตถุประสงค์

- พัฒนาเว็บแอปพลิเคชันสำหรับจัดการคลังหนังสือส่วนตัว
- ให้ผู้ใช้ติดตามความคืบหน้าของการอ่านหนังสือแต่ละเล่มได้
- ให้ผู้ใช้จัดหมวดหมู่และจัดการสถานะของหนังสือได้อย่างสะดวก
- ให้ผู้ใช้กำหนดเป้าหมายการอ่านและติดตามผลการดำเนินงานได้
- ให้ผู้ใช้บันทึกความคิดเห็น คะแนน และบันทึกส่วนตัวเกี่ยวกับหนังสือได้
- แสดงสถิติและข้อมูลสรุปเกี่ยวกับพฤติกรรมการอ่านของผู้ใช้

## 3. กลุ่มผู้ใช้งาน

ระบบออกแบบมาสำหรับบุคคลที่ชื่นชอบการอ่านหนังสือและต้องการจัดการการอ่านของตนเอง โดยผู้ใช้งานสามารถ

- จัดเก็บและจัดการข้อมูลหนังสือส่วนตัว
- ติดตามหนังสือที่อ่านแล้วและหนังสือที่กำลังอ่าน
- บันทึกความคืบหน้าของการอ่าน
- กำหนดเป้าหมายการอ่าน
- บันทึกความคิดเห็นและรีวิวหนังสือ
- ดูสถิติและวิเคราะห์พฤติกรรมการอ่านของตนเอง

## 4. ความต้องการด้านฟังก์ชัน

### 4.1 ระบบ Dashboard

แสดงภาพรวมกิจกรรมการอ่านของผู้ใช้งาน ประกอบด้วย

- จำนวนหนังสือทั้งหมดในคลัง
- จำนวนหนังสือที่กำลังอ่าน อ่านจบแล้ว และต้องการอ่าน
- เป้าหมายการอ่านและความคืบหน้าของเป้าหมาย
- หนังสือที่เพิ่มเข้ามาล่าสุด
- หนังสือที่มีการอัปเดตความคืบหน้าล่าสุด
- ข้อมูลสรุปและสถิติการอ่าน

### 4.2 ระบบจัดการหนังสือ (Book Management)

- เพิ่ม แก้ไข และลบหนังสือในคลังส่วนตัว
- แสดงรายละเอียดหนังสือ ได้แก่ ชื่อหนังสือ ผู้แต่ง รูปปก ประเภท คำอธิบาย และจำนวนหน้าทั้งหมด
- ค้นหาหนังสือจากชื่อหนังสือหรือชื่อผู้แต่ง
- เรียงลำดับตามชื่อ วันที่เพิ่ม คะแนน หรือความคืบหน้าในการอ่าน
- กรองหนังสือตามประเภทและสถานะการอ่าน

### 4.3 ระบบจัดการสถานะการอ่าน (Reading Status Management)

ระบบรองรับสถานะการอ่านดังต่อไปนี้ และผู้ใช้สามารถเปลี่ยนสถานะได้ตามต้องการ

| สถานะ                | คำอธิบาย                     |
| -------------------- | ---------------------------- |
| Want to Read         | หนังสือที่ต้องการอ่านในอนาคต |
| Reading              | หนังสือที่กำลังอ่านอยู่      |
| Completed            | หนังสือที่อ่านจบแล้ว         |
| Paused               | หนังสือที่หยุดอ่านชั่วคราว   |
| Did Not Finish (DNF) | หนังสือที่ตัดสินใจอ่านไม่จบ  |

### 4.4 ระบบติดตามความคืบหน้าการอ่าน (Reading Progress Tracking)

- อัปเดตหน้าปัจจุบันที่กำลังอ่าน
- แสดงหน้าปัจจุบันเทียบกับจำนวนหน้าทั้งหมด
- คำนวณเปอร์เซ็นต์ความคืบหน้าโดยอัตโนมัติ และแสดงผลผ่าน Progress Bar
- บันทึกวันที่เริ่มอ่านและวันที่อ่านจบ
- เปลี่ยนสถานะเป็น Completed อัตโนมัติเมื่ออ่านครบทุกหน้า หรือให้ผู้ใช้เปลี่ยนด้วยตนเอง

### 4.5 ระบบตั้งเป้าหมายการอ่าน (Reading Goals)

- กำหนดเป้าหมายจำนวนหนังสือที่ต้องการอ่านภายในหนึ่งปี
- แสดงจำนวนหนังสือที่อ่านจบเทียบกับเป้าหมาย และจำนวนที่เหลือ
- แสดงเปอร์เซ็นต์ความสำเร็จของเป้าหมาย
- แก้ไขเป้าหมายการอ่านได้

### 4.6 ระบบบันทึกการอ่าน (Reading Journal)

- เขียนบันทึกเกี่ยวกับหนังสือ
- บันทึกข้อความหรือคำคมที่ชื่นชอบ
- บันทึกความคิดและข้อสรุปจากการอ่าน
- แก้ไขและลบบันทึกได้
- เชื่อมโยงบันทึกและคำคมกับหนังสือแต่ละเล่ม

### 4.7 ระบบให้คะแนนและรีวิว (Rating and Review)

- ให้คะแนนหนังสือ
- เขียน แก้ไข และลบรีวิว
- แสดงคะแนนและรีวิวในหน้ารายละเอียดหนังสือ

### 4.8 ระบบสถิติการอ่าน (Reading Statistics)

- จำนวนหนังสือที่อ่านจบทั้งหมด และจำนวนหน้าที่อ่านทั้งหมด
- จำนวนหนังสือที่อ่านจบในแต่ละเดือนและแต่ละปี
- ประเภทหนังสือที่อ่านมากที่สุด
- คะแนนเฉลี่ยของหนังสือที่ให้คะแนน
- ความคืบหน้าและการบรรลุเป้าหมาย
- แสดงสถิติในรูปแบบกราฟหรือแผนภูมิ

### 4.9 ระบบบันทึกช่วงเวลาการอ่าน (Reading Session Tracking)

- เริ่มและหยุดจับเวลาการอ่าน
- บันทึกวันที่และระยะเวลาของการอ่านแต่ละครั้ง
- บันทึกหน้าที่เริ่มอ่านและหน้าที่อ่านถึง พร้อมคำนวณจำนวนหน้าที่อ่านในแต่ละครั้ง
- แสดงประวัติการอ่านในแต่ละ Session

## 5. ความต้องการที่ไม่ใช่ด้านฟังก์ชัน

### 5.1 ด้านการใช้งาน (Usability)

- หน้าตาและรูปแบบการใช้งานเข้าใจง่าย มีโครงสร้างเมนูที่ชัดเจน
- เข้าถึงฟังก์ชันหลักได้โดยไม่ต้องดำเนินการหลายขั้นตอนเกินความจำเป็น
- แจ้งผลการดำเนินการให้ผู้ใช้ทราบอย่างชัดเจน

### 5.2 ด้านประสิทธิภาพ (Performance)

- โหลดหน้าเว็บภายในระยะเวลาที่เหมาะสม
- ค้นหาและกรองข้อมูลได้อย่างรวดเร็ว
- รองรับข้อมูลหนังสือจำนวนมากโดยไม่ส่งผลกระทบต่อประสิทธิภาพอย่างมีนัยสำคัญ

### 5.3 ด้านความน่าเชื่อถือ (Reliability)

- บันทึกข้อมูลของผู้ใช้ได้อย่างถูกต้อง
- ป้องกันการบันทึกค่าความคืบหน้าการอ่านที่ไม่ถูกต้อง
- รักษาความสอดคล้องของข้อมูลหนังสือเมื่อมีการแก้ไข

### 5.4 ด้านการรองรับอุปกรณ์ (Responsiveness)

- รองรับการใช้งานบนคอมพิวเตอร์ แท็บเล็ต และโทรศัพท์มือถือ
- ปรับรูปแบบหน้าเว็บให้เหมาะสมกับขนาดหน้าจอ
- ปุ่มและองค์ประกอบต่าง ๆ ใช้งานได้สะดวกบนหน้าจอขนาดเล็ก

### 5.5 ด้านความถูกต้องของข้อมูล (Data Integrity)

- หน้าปัจจุบันที่อ่านต้องไม่เกินจำนวนหน้าทั้งหมดของหนังสือ
- ความคืบหน้าการอ่านต้องไม่เป็นค่าติดลบ
- ชื่อหนังสือเป็นข้อมูลที่จำเป็นในการเพิ่มหนังสือ
- คะแนนหนังสือต้องอยู่ในช่วงที่ระบบกำหนด
- ตรวจสอบความถูกต้องของข้อมูลก่อนบันทึกทุกครั้ง

## 6. โครงสร้างข้อมูล

ระบบจัดเก็บข้อมูลของหนังสือแต่ละเล่มดังนี้

| ฟิลด์          | คำอธิบาย                   |
| -------------- | -------------------------- |
| Book ID        | รหัสหนังสือที่ไม่ซ้ำกัน    |
| Title          | ชื่อหนังสือ                |
| Author         | ชื่อผู้แต่ง                |
| Cover Image    | รูปปกหนังสือ               |
| Genre          | ประเภทหนังสือ              |
| Description    | คำอธิบายหนังสือ            |
| Total Pages    | จำนวนหน้าทั้งหมด           |
| Current Page   | หน้าปัจจุบันที่กำลังอ่าน   |
| Reading Status | สถานะการอ่าน               |
| Rating         | คะแนนที่ผู้ใช้ให้          |
| Review         | รีวิวหนังสือ               |
| Start Date     | วันที่เริ่มอ่าน            |
| Finish Date    | วันที่อ่านจบ               |
| Date Added     | วันที่เพิ่มหนังสือเข้าระบบ |

นอกจากนี้ ระบบต้องจัดเก็บข้อมูลเป้าหมายการอ่าน บันทึกการอ่าน คำคม และประวัติ Reading Session

## 8. ขอบเขตของโครงการ

### เวอร์ชันแรก (Version 1)

มุ่งเน้นฟังก์ชันหลัก ได้แก่

- การจัดการหนังสือ
- การจัดการสถานะการอ่าน
- การติดตามความคืบหน้าการอ่าน
- การตั้งเป้าหมายการอ่าน
- การแสดงข้อมูลสรุปบนหน้า Dashboard

### ระยะต่อไป

- Reading Journal
- Reading Session Tracking
- สถิติขั้นสูง
- การเชื่อมต่อ API ภายนอก

เป้าหมายของเวอร์ชันแรกคือการสร้างเว็บแอปพลิเคชันที่ใช้งานได้จริง มีโครงสร้างชัดเจน และรองรับการต่อยอดไปสู่ระบบ Full Stack ในอนาคต

## 9. แผนพัฒนาในอนาคต

- ค้นหาหนังสือผ่าน API ภายนอก และดึงข้อมูลหนังสืออัตโนมัติ
- ค้นหาหนังสือด้วย ISBN และสแกนบาร์โค้ดหนังสือ
- ระบบสมัครสมาชิกและเข้าสู่ระบบ
- จัดเก็บข้อมูลบน Cloud Database และซิงโครไนซ์ข้อมูลระหว่างอุปกรณ์
- ระบบแนะนำหนังสือ
- ส่งออกประวัติการอ่าน
- แจ้งเตือนให้กลับมาอ่านหนังสือ
- ติดตาม Reading Streak
